# Habitloop — `roadmap.md` · EXAMPLE

## Now — v0.1 MVP (TestFlight) · ~6 weeks

Create habits · daily check-in (done/skip) · streaks · local reminders · simple stats ·
optional Apple sign-in. **Goal:** validate that people check in daily.

## Next — v1.0 (App Store)

Polish, onboarding A/B, empty-state copy, App Store assets, crash-free ≥ 99.5%.
**Gate:** Day-7 retention ≥ 30% in beta.

## Later — v1.1 Cloud sync

Supabase sync across devices; conflict resolution; account management.

## Later — v1.2 Android

React Native already cross-platform; add Android notifications + Material polish.

## Future — v2 Social & widgets (candidates, not committed)

Home-screen widgets · share a streak · accountability buddy · weekly/custom schedules.

> Roadmap items are **directions, not promises** — reprioritize from metrics each cycle.
